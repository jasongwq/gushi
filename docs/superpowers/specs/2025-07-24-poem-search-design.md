# 古诗集合页面搜索功能设计

## 概述

在古诗集合页面（PoemCollectionPage）添加搜索功能，支持按标题、作者、内容模糊匹配，标题权重最高。

## 搜索交互流程

**搜索框**：在页面顶部（分类标签栏上方）添加固定的搜索输入框，带搜索图标和清除按钮。

**交互流程**：
1. 默认状态：搜索框为空，显示占位提示文字"搜索古诗…"，下方展示分类标签 + 列表
2. 输入关键词：隐藏分类标签栏，实时展示搜索结果列表（扁平列表，无分组）
3. 搜索结果列表中每首古诗的展示样式与现有分类列表一致（标题、朝代·作者、掌握等级）
4. 点击清除按钮或清空输入框：恢复分类视图
5. 无结果时：显示"未找到相关古诗"提示

## 搜索范围与权重

- 标题匹配：最高优先级，排在最前
- 作者匹配、内容匹配：同等权重，排在标题匹配之后
- 同级内按原始数据顺序排列

## 模糊匹配算法

**匹配规则**：
- 子序列匹配：输入关键词按字符逐个匹配，不要求连续，但要求顺序一致
- 例如输入"静思"可匹配"静夜思"；输入"李白"可匹配"李 白"
- 同时支持精确子串匹配（如输入"夜思"匹配"静夜思"）
- 不区分大小写

**排序逻辑**：
1. 标题匹配的诗 → 按原始顺序
2. 作者匹配的诗 → 按原始顺序（已出现在标题匹配中的不重复）
3. 内容匹配的诗 → 按原始顺序（已出现在上面中的不重复）

一首诗可能同时在标题和内容中匹配，但只出现一次，以最高优先级的位置为准。

## 实现方式

- 在 `PoemCollectionPage.vue` 中新增 `searchQuery` ref 和 `searchResults` computed
- `searchResults` 内部：遍历 `enabledPoems`，分别收集标题匹配、作者匹配、内容匹配三个集合，合并去重
- 模糊匹配函数抽取为 `utils/search.ts` 工具函数，保持组件简洁
- 零额外依赖，纯前端 computed 过滤

## UI 与样式

**搜索框**：
- 位于页面顶部，分类标签栏上方
- 圆角输入框，浅灰背景（`bg-gray-100`），与现有页面风格一致
- 左侧搜索图标（SVG 内联图标，不引入图标库）
- 右侧清除按钮（×），仅在输入框有内容时显示
- 占位提示文字："搜索古诗…"
- 输入框获焦时边框高亮（ring indigo 色）

**搜索结果列表**：
- 复用现有古诗卡片样式（`p-3 bg-white border border-gray-200 rounded-lg shadow-sm`）
- 无分组，扁平列表
- 列表项之间间距与现有列表一致

**空状态**：
- 居中显示"未找到相关古诗"文字
- 灰色弱化提示

**页面布局变化**：
```
搜索框（新增）
─────────────
分类标签栏（搜索时隐藏）
─────────────
古诗列表 / 搜索结果列表
```
