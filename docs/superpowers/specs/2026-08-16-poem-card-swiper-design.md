# 家长抽查页面 — 抽卡式古诗切换设计

## 概述

将家长抽查页面重新设计为"抽卡"模式：古诗以卡片形式横向排列，支持左右滑动切换和随机抽卡，替代现有的逐首顺序抽查流程。

## 页面入口与流程

1. 首页点"家长抽查" → 进入新页面 `PoemCardPage`
2. 页面顶部有筛选栏（年级/来源），默认显示所有启用的古诗
3. 中间是横向滚动卡片组，中间卡片最大，两侧缩小预览
4. 底部工具栏：随机抽卡按钮 + 统计信息

### 与现有页面的关系

- **`RecitationPlayPage`**（逐首标记的抽查流程）→ 家长抽查入口不再跳转此页面，改为跳转 `PoemCardPage`
- **`RecitePage`**（自评背诵，先隐藏再揭示）→ 保留，交互逻辑不同
- **`QuizSetupPage`** 家长模式的古诗抽背选项 → 简化，直接进入 `PoemCardPage`
- **`QuizPlayPage`**（补字选择/上下句接龙）→ 保留，不受影响
- `RecitationPlayPage` 保留供其他入口使用，不删除

## 卡片组件设计

### 卡片状态

- **收起状态**：只显示标题
- **展开状态**：点击后一次性揭示作者/朝代 + 全文 + 逐行标记按钮（卡顿/不会）+ 译文切换

### 卡片交互

- 点击卡片：收起 ↔ 展开
- 左右滑动：切换卡片，跟手移动，松手惯性滑动或回弹
- 滑走即完成该诗：未标记的行默认"熟练"，标记过的行保持标记
- 不需要"完成"按钮

## 横向卡片组布局

```
[缩小]  [缩小]  [===大卡片===]  [缩小]  [缩小]
  p-2     p-1       当前         p+1     p+2
```

- 当前卡片：`scale(1)`, `opacity(1)`, 居中
- 相邻卡片：`scale(0.85)`, `opacity(0.6)`, 两侧露出约 30% 宽度
- 更远卡片：`scale(0.7)`, `opacity(0.3)`, 只露边缘

## 实现方案：纯手写 CSS 动画 + Touch 事件

零依赖，与项目"纯 Tailwind 无 UI 库"风格一致。

### 滑动实现

- 监听 `touchstart/touchmove/touchend` 事件
- 滑动时：卡片跟随手指移动（`translateX`）
- 松手后：根据滑动速度和距离判断切换到下一张或回弹
- 惯性动画：`requestAnimationFrame` + 缓动函数
- 边界处理：首尾卡片滑到边界时弹性回弹

### 洗牌动画

点击"随机抽卡"按钮：
1. 卡片快速左右滚动 2-3 秒（速度递减）
2. 最后减速停在随机一张
3. 播放轻微"弹跳"效果表示选中

## 顶部筛选与统计

- 筛选：年级标签（横滑选择）、来源（全部/错题本/不熟练）
- 统计：已抽查 X 首 / 共 Y 首
- 卡片角标：已标记过的诗显示小图标（"已查"）

## 标记逻辑

- 展开卡片后，每行有"卡顿/不会"按钮（与现有 RecitationCard 一致）
- 标记结果实时记录到 learning store
- 滑走时自动保存：未标记的行 = 熟练，标记过的行保持标记
- 不需要"完成"按钮

## 数据流

- 进入页面时，从 `poemStore` 获取所有启用的古诗列表
- 筛选后生成卡片数组，维护当前索引 `currentIndex`
- 滑动/抽卡改变 `currentIndex`
- 展开卡片后标记结果实时写入 `learningStore`
- 滑走时自动完成该诗的记录
- 离开页面时，整体结果已保存，无需专门的"结果页"

## 不区分模式

- 不区分家长/自背模式，统一交互
- 卡片统一用"卡顿/不会"标记
- 家长抽查和自评背诵共用同一页面
