# 古诗卡片浏览交互优化

## 背景

当前浏览层和详情层之间的切换交互体验不佳：
- 长按返回太难点触发
- 浏览层和详情层之间没有过渡动画
- 卡片中间太空，布局不自适应

## 设计

### 1. 进入详情：点击卡片 + 放大动画

- 交互方式：点击卡片进入详情（保留原方式，不变）
- 动画：卡片从当前大小放大到全屏详情页（`scale(0.85) → scale(1)` + 淡入，0.35s）
- 不在浏览层添加任何滑动进入详情的手势（避免与 Swiper 切卡片冲突）

### 2. 退出详情：左右滑动 + 缩小动画

- 交互方式：在详情页左右滑动超过阈值（100px）触发返回
- 动画：详情页从全屏缩小回卡片大小（`scale(1) → scale(0.85)` + 淡出，0.25s）
- 滑动阈值：100px，与之前长按的意图一致——明确的操作意图
- 保留"← 返回"按钮作为备选

### 3. 浏览层卡片尺寸

- 卡片大小由内容自适应，不写死百分比高度
- Swiper slide 宽度保持 65%（略窄，减少空白感）
- 卡片高度由内容撑开，不强制填满容器
- 卡片内部 padding 和字体适当缩小（`p-5`、`text-xl`），更紧凑

### 4. 详情页布局自适应

- 整体页面不出现滚动条，使用 flex 布局自适应
- 古诗正文区域（逐句标记区）设为 `flex-1 overflow-y-auto`，内容过长时仅该区域滚动
- 标题、朝代作者、操作按钮、上一首/下一首按钮固定在正文区域上下

### 5. 移除的交互

- 移除浏览层的"长按进度条进入详情"（改为点击卡片）
- 移除详情层的"长按底部返回浏览"（改为左右滑动）
- 移除浏览层整体的左右滑动进入详情（避免与 Swiper 冲突）

## 涉及文件

| 文件 | 改动 |
|------|------|
| `PoemCardPage.vue` | 移除浏览层滑动进入详情手势；详情层改为左右滑动返回；添加 Transition 放大/缩小动画；布局改为 flex 自适应 |
| `PoemCard.vue` | 卡片尺寸自适应，缩小 padding/字体 |
| `CardSwiper.vue` | slide 宽度 65%，高度自适应 |
| `RecitationCard.vue` | 古诗正文区域改为 flex-1 + overflow-y-auto，整体布局自适应 |
