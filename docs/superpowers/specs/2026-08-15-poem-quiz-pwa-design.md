# 古诗抽查 PWA 设计文档

## 概述

面向小学生的古诗背诵抽查工具，PWA 形式，支持离线使用。家长可抽查孩子，孩子也可自主练习。内置小学部编版古诗，支持四种抽查方式、错题记录、艾宾浩斯遗忘曲线复习、不熟练标注。

## 技术栈

| 层级 | 选型 | 理由 |
|------|------|------|
| 构建工具 | Vite | 快速构建，PWA 插件生态好 |
| 语言 | TypeScript | 类型安全，代码组织清晰 |
| UI 框架 | Vue 3 | 轻量，适合中小型 SPA，中文社区活跃 |
| UI 组件 | 手写简约组件 | 避免引入重依赖，保持风格统一 |
| PWA | vite-plugin-pwa | 自动生成 Service Worker，支持离线缓存 |
| 样式 | CSS 变量 + 少量 Tailwind | 简约现代，CSS 变量做主题，Tailwind 做布局 |
| 语音识别 | WebGPU + Sherpa-ONNX（或类似） | 离线本地推理，v2 功能 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| 数据存储 | localStorage + 导出/导入 JSON | 本地优先，手动备份 |

## 核心页面

1. **首页** — 今日待复习提示 + 模式选择（家长抽查 / 自主练习）
2. **古诗抽查** — 随机抽诗，4 种抽查方式
3. **错题本** — 错题列表 + 重做
4. **学习进度** — 按诗/按单元的掌握情况，遗忘曲线复习日历
5. **设置** — 导出/导入数据、古诗范围选择

## 数据模型

### 古诗数据结构（poems.json）

```typescript
interface Poem {
  id: string;              // 唯一标识，如 "b1-01"
  title: string;           // 诗名
  author: string;          // 作者
  dynasty: string;         // 朝代
  grade: string;           // 年级，如 "一年级上"
  unit: string;            // 单元，如 "第一单元"
  text: string[];          // 诗句数组，每句一行
  textType: "五言" | "七言" | "其他";
}
```

### 学习记录结构（localStorage）

```typescript
interface LearningRecord {
  poemId: string;
  lastReviewDate: string;    // ISO 日期
  reviewCount: number;       // 已复习次数
  nextReviewDate: string;    // 下次应复习日期
  correctness: number[];     // 每次复习的对错记录 [1,0,1,1]
  masteryLevel: "新" | "学" | "熟" | "固";
  unproficient: boolean;     // 不熟练标注
  unproficientCorrectStreak: number;  // 连续答对计数
  lastLearnDate?: string;    // 最近学习日期
}

interface QuizResult {
  poemId: string;
  quizType: "fillBlank" | "nextLine" | "selectTitle" | "recite";
  date: string;
  correct: boolean;
  wrongAnswer?: string;      // 错误答案记录
}

interface WrongEntry {
  poemId: string;
  quizType: "fillBlank" | "nextLine" | "selectTitle" | "recite";
  wrongCount: number;
  lastWrongDate: string;
  unproficient: boolean;
}

interface UserData {
  records: LearningRecord[];
  quizResults: QuizResult[];
  wrongBook: WrongEntry[];
  settings: UserSettings;
  lastSyncDate?: string;
}
```

## 艾宾浩斯遗忘曲线

| 复习次数 | 间隔 | 掌握度 |
|---------|------|--------|
| 0 | — | 新 |
| 1 | 1 天 | 学 |
| 2 | 2 天 | 学 |
| 3 | 4 天 | 熟 |
| 4 | 7 天 | 熟 |
| 5 | 15 天 | 固 |
| 6+ | 30 天 | 固 |

每次复习答错，间隔回退一级（如 4 天→2 天），不重置为 0。

## 四种抽查方式

### 1. 补字选择题（fillBlank）

- **出题**：随机选一首诗，从诗句中挖空 1-3 个字
- **展示**：显示诗名+作者，诗句中空白处用下划线标注，如 `春眠不觉_，处处闻_鸟`
- **选项**：每个空白处提供 6 个候选字（1 正确 + 5 干扰项）
- **干扰项**：从同诗其他字 + 同年级其他诗的常见字中生成
- **作答**：点击选项选择，即时判对错
- **难度**：可设置挖空数量（1/2/3个）

### 2. 上下句接龙选择题（nextLine）

- **出题**：随机选一首诗，给出上句或下句
- **展示**：显示一句诗 + 6 个选项，如 `显示：春眠不觉晓 → 以下哪句是下句？`
- **选项**：6 个选项（1 正确 + 5 干扰项）
- **干扰项**：同年级其他诗的句子 + 常见名句
- **作答**：点击选项，即时判对错
- **变体**：可设置"给上句接下句"或"给下句接上句"

### 3. 看诗选标题/作者/朝代（selectTitle）

- **出题**：显示一首诗的全文，下方显示 6 个选项
- **选项类型**：三种模式 — 选诗名 / 选作者 / 选朝代
- **选项**：6 个选项（1 正确 + 5 干扰项），干扰项为同年级其他诗的标题/作者/朝代
- **作答**：点击选项，即时判对错

### 4. 语音背诵（recite）— v2

- **出题**：显示诗名，孩子需要背诵全文 + 作者 + 朝代
- **完整背诵内容**：诗句 + 朝代 + 作者，如 `春眠不觉晓，处处闻啼鸟。夜来风雨声，花落知多少。唐·孟浩然`
- **作答**：点击录音按钮，WebGPU 语音识别引擎实时转文字
- **判分**：识别文本与原文比对，分别标记诗句、作者、朝代的遗漏/错误
- **评分**：诗句/作者/朝代分开计分，缺朝代或缺作者扣分但不全扣
- **降级**：浏览器不支持 WebGPU 时，切换为"家长评判模式" — 孩子背完后家长手动标记对错

## 抽题来源与智能混合算法

### 抽题来源选项

| 选项 | 说明 |
|------|------|
| 智能混合（默认） | 优先从待复习、不熟练、错题本、最近背诵中抽题，少量从全部中随机 |
| 按年级 | 选择一个或多个年级 |
| 按单元 | 选择具体单元 |
| 全部 | 所有古诗 |
| 仅待复习 | 遗忘曲线今日需复习的 |
| 错题本 | 仅从错题中抽题 |
| 不熟练 | 仅从标注为不熟练的诗中抽题 |

### 智能混合抽题算法（默认）

| 来源 | 占比 | 说明 |
|------|------|------|
| 待复习 | 30% | 遗忘曲线今日需复习的诗 |
| 不熟练 | 25% | 标注为不熟练的诗 |
| 错题本 | 20% | 之前答错过的诗 |
| 最近背诵 | 15% | 最近 7 天内学过的诗 |
| 全部随机 | 10% | 随机抽取，防止遗忘旧诗 |

- 若某来源不足，剩余名额顺延到下一优先级
- 顺序：待复习 → 不熟练 → 错题本 → 最近背诵 → 全部随机

### 不熟练标注

- 每首诗可手动标注为"不熟练"（在错题本、学习进度、答题结果页均可标注）
- 不熟练的诗会自动加入错题本的优先复习队列
- 答对 3 次连续后，自动取消"不熟练"标注（也可手动取消）
- 不熟练标注作为独立数据，与错题记录分离

## 页面交互流程

### 首页

```
┌─────────────────────────────┐
│  古诗抽查                    │
│                              │
│  今日待复习：3 首             │
│  ┌──────────────────────┐   │
│  │  点击进入复习 →       │   │
│  └──────────────────────┘   │
│                              │
│  ─── 选择模式 ───           │
│  ┌──────────┐ ┌──────────┐  │
│  │ 家长抽查  │ │ 自主练习  │  │
│  └──────────┘ └──────────┘  │
│                              │
│  ─── 快捷入口 ───           │
│  错题本(5)  学习进度  设置   │
└─────────────────────────────┘
```

### 家长抽查 / 自主练习流程

1. **选择范围** → 智能混合（默认）/ 年级/单元/全部/仅待复习/错题本/不熟练
2. **选择抽查方式** → 补字/接龙/选标题/选作者/选朝代（可多选）
3. **设置数量** → 5/10/20
4. **开始答题** → 逐题作答，每题即时反馈
5. **结果页** → 正确率、用时、错题列表，一键加入错题本，可标注不熟练

### 错题本

- 列表展示：诗名 | 错误类型 | 错误次数 | 最近错误日期 | 不熟练标注
- 操作：重做（原题重新作答）、移除（已掌握）、标注/取消不熟练
- 筛选：按错误类型/年级/不熟练

### 学习进度

- 总览：已学/总数、掌握度分布（新/学/熟/固）、不熟练数量
- 按年级：每首诗的掌握状态 + 不熟练标记
- 复习日历：未来 7 天待复习诗数

### 设置

- 导出数据（JSON）
- 导入数据（JSON）
- 古诗范围选择（年级开关）
- 清除数据

## PWA 与离线策略

### Service Worker 缓存策略

| 资源类型 | 策略 | 说明 |
|---------|------|------|
| HTML/JS/CSS | Cache First | 构建时预缓存，离线可用 |
| poems.json | Cache First | 古诗数据随应用一起缓存 |
| 语音模型文件 | Cache First + 懒加载 | 首次使用时下载，之后缓存 |
| 字体/图标 | Cache First | 静态资源长期缓存 |

### 安装体验

- 首次访问时，浏览器提示"添加到主屏幕"
- 自定义启动图标和启动画面
- 安装后全屏运行，无浏览器地址栏

### 离线能力

- 所有核心功能（补字、接龙、选标题/作者/朝代）完全离线可用
- 语音背诵需首次联网下载模型，之后离线可用
- 数据导出/导入离线可用

### 更新机制

- 检测到新版本时，后台静默更新 Service Worker
- 更新完成后提示"有新版本可用，点击刷新"
- 用户主动刷新后生效，不强制中断当前答题
