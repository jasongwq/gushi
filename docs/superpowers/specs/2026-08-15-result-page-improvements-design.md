# 抽查结果页改进 & 答题完成直接显示结果

## 背景

当前抽查结果页对题只显示诗题和✓，不展示题目文本和用户选择，用户无法回顾答题内容。另外答完最后一题后有"答题完成！查看结果"中间页面，需要手动点击才能看到结果，体验不够流畅。

## 需求

### 1. 结果页展示题目文本+你的选择+正确答案

每道题都展示：
- 题号 + 诗题 + ✓/✗
- 题目文本（prompt）
- 你的选择（对题绿色，错题红色标注）
- 正确答案（仅错题时额外显示，因为对题你的选择=正确答案无需重复）

### 2. 答完最后一题直接显示结果

删除"答题完成！查看结果"中间页面。答完最后一题后保留1.5秒正确/错误反馈，然后自动跳转结果页。

## 变更范围

### QuizResultPage.vue

- 每道题的卡片都展示 prompt 文本
- 每道题都展示用户选择的选项（`item.selected`）
- 错题额外展示正确答案（`item.correct`），对题不再重复

### QuizPlayPage.vue

- 删除 `isFinished` 时的"答题完成！"中间页面
- 在 `selectAnswer` 中，当答完最后一题后（`quizStore.isFinished` 为 true），1.5秒反馈结束后自动 `$router.push({ name: 'quiz-result' })`
